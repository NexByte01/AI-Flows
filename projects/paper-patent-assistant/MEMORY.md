# MEMORY.md — 项目长期记忆

## 项目背景

- **项目名称**：`学术论文与专利协作平台`
- **项目 slug**：`paper-patent-assistant`
- **项目类型**：`app`
- **目标用户**：`高校师生、研发工程师、专利代理人`
- **核心目标**：`整合学术写作润色、模拟盲审、学术转专利语言与权利要求书校验的一站式科研工作台`
- **创建日期**：`2026-06-01`

## 技术栈决策

| 决策 | 选择 | 理由 | 日期 |
|---|---|---|---|
| 运行框架 | HTML5 + JavaScript + Vite | 轻量化、零编译负担，Vite 提供极佳的 HMR 开发体验 | 2026-06-01 |
| 样式系统 | Vanilla CSS + HSL variables | 最大化排版掌控力与加载速度，方便配置科幻深色调配色 | 2026-06-01 |
| 图标库 | Lucide Icons | 简洁现代的开源图标集 | 2026-06-01 |

## 持久约定

- 核心功能代码与页面样式保留在 `projects/paper-patent-assistant/` 内，不得向全局根目录溢出。
- 遵循 Nature-style 写作与审稿规范开发润色评估提示词。
- 遵循专利权利要求书独立/从属编写规范设计校验分析逻辑。
- **AI 引擎调用决策**：暂时不接入或调用外部网络 API，所有核心功能保持在本地纯前端 Mock 演示，实际的 AI 协作与翻译转换完全在本 Agent 对话中进行。
