仓库里有什么

  • 通过 `AGENTS.md`、`MEMORY.md` 和 `memory/` 持续保留上下文
  • 通过 `.agents/skills/` 与 `.agents/workflows/` 沉淀能力和流程
  • 通过 GitHub Actions 运行日报、Issue 处理和 Pages 部署
  • 通过 `media-platform/` 等目录持续孵化实验项目

当前阶段

这个站点当前先承担“品牌切换”和“仓库入口”职责，不追求完整官网形态。 下一阶段会根据主站结构和内容规划，决定是继续作为镜像说明页，还是升级为更完整的导航站。

为什么这样做

AI 工具真正有价值的部分，不只是生成内容，而是能否积累记忆、沉淀流程、复用技能，并持续参与项目建设。 NexByte AI Flows 就是围绕这件事设计的。

后续入口

如果你是第一次访问，优先查看主站和 GitHub 仓库；如果你是协作者，直接从仓库里的 `AGENTS.md` 与 `MEMORY.md` 开始。
